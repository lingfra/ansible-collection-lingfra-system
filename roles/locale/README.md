# Ansible Role: lingfra.system.locale

Configures locale information and generates them.

## Supported Platforms

Not specified.

## Entrypoint `main` - Main entry point for locale role

This role configures system locales.
It is recommended to read and understand [Locale (ArchWiki)](https://wiki.archlinux.org/title/Locale#Setting_the_locale).

The list of choices for the options [`locale_gen_list`](#locale_gen_list) and [`locale_conf_lang`](#locale_conf_lang) are generated from the [`localedata/SUPPORTED` file of the glibc upstream repository](https://sourceware.org/git/?p=glibc.git;a=blob;f=localedata/SUPPORTED;h=089a5489cb4627379cd475f5d872cbd7737d9a81;hb=HEAD).
If your locale is not present in the choices list, please open an issue and / or pull request.

### Options for `main`

#### `locale_chroot_path`

Type: `str`, optional.

If specified, all actions are executed inside the chroot.

#### `locale_conf_extra_options`

Type: `dict`, optional.

Extra options for `/etc/locale.conf`. Refer to [**locale(7)**](https://man.archlinux.org/man/locale.7) for a description of possible values.
