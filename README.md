# Ansible Collection - lingfra.system

An Ansible collection for managing and configuring core operating system
functions.

## Included Content

### Roles

- [apt_source](./roles/apt_source/README.md): Configure APT sources on Deb-based
systems.
- [pacman](./roles/pacman/README.md): Configures the Pacman package manager and
its mirrors.
- [pkgs](./roles/pkgs/README.md): Install and remove system packages.
- [sd_network](./roles/sd_network/README.md): Configure systemd-network to
create VLANs and bridge devives.

### Playbooks

- [apt_source](./playbooks/apt_source.yaml)
- [initial_provision](./playbooks/initial_provision.yaml): Similar to the
[provision](./playbooks/provision.yaml) playbook this performs basic provisioning tasks, but
also performs some non-idempotent tasks that are sometimes required on fresh hosts.
- [pacman_key_reinit](./playbooks/pacman_key_reinit.yaml): This playbook
re-initializes the pacman trust database by deleting, re-initializing and
populating it. This is a shortcut to a task file from the
[pacman](./roles/pacman/README.md) role (in particular
[pacman_key_reinit.yaml](./roles/pacman/tasks/pacman_key_reinit.yaml)).
- [pkg_manager](./playbooks/pkg_manager.yaml): Configures the distribution
specific package manager (currently only pacman is supported).
- [pkgs](./playbooks/pkgs.yaml)
- [provision](./playbooks/provision.yaml): Performs basic provisioning tasks on the
host.
- [sd_network](./playbooks/sd_network.yaml)

## Installation

The collection can be obtained from the Git repository. This may be desirable to
get the latest development version. The following `requirements.yaml` entry, can
be used to download directly from Git:

```yaml
---
collections:
  - name: https://codeberg.org/lingfra/ansible-collection-lingfra-system
    version: main
    type: git
```

For more information, see the [Installing
collections](https://docs.ansible.com/ansible/latest/collections_guide/collections_installing.html)
section of the Ansible documentation.

## Documentation

Role documentation (`roles/foo/README.md`) is generated by
[aar-doc](https://pypi.org/project/aar-doc/) based on the role's
`meta/argument_specs.yaml` file. See [.aar_doc.yml](./.aar_doc.yml) for the
configuration. The templates are maintained in a separate repository:
[lingfra/aar-doc-config](https://codeberg.org/lingfra/aar-doc-config).

Example for generating the `README.md` file for a role named _foo_:

```bash
aar-doc roles/foo markdown
```
