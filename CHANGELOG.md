## [0.1.0]

Initial release of collection. It is a loose mix of roles and playbooks useful
for system administration and provisioning.

- Configure APT sources for Debian based distributions.
- Configure and build the initramfs for Arch Linux based distributions.
- Configure the Pacman package manager.
- Install and remove system packages.
- Configure systemd-network to create VLANs and bridge devives.
